Bem-vindo à documentação do **Quayer**.

## O que você vai encontrar aqui

- **Builder IA** — como criar e publicar agentes WhatsApp via conversação com o meta-agente.
- **API** — referência completa dos endpoints REST (gerada a partir do OpenAPI do Igniter.js).
- **Integrações** — WhatsApp (UAZapi), provedores OAuth, webhooks.
- **Operações** — runbooks, deploy, observabilidade.

## Stack

A plataforma é construída sobre:

- **Next.js 16** (App Router) + **Igniter.js** no backend
- **Prisma** + **PostgreSQL** (Supabase em produção)
- **Tailwind v4** + **shadcn/ui** + Design System v3
- **BullMQ** para jobs assíncronos
