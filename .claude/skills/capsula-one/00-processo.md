# Skill: Processo Empreendedor Completo (Cápsula One)

## Quando usar
- Quando precisa decidir qual etapa do negócio priorizar
- Quando está avaliando se está no momento certo para investir, escalar ou pivotar
- Quando discute roadmap estratégico de longo prazo
- Como referência geral do processo da ideia à escala

## Framework Core — Roadmap da Ideia à Escala

### Fase 1: Bootstrapping (1-2 anos, FFF Money)
```
Ideia/Propósito → Segmentar Mercado → Descobrir Cliente → Validar Solução → Testar Modelo de Receita
```

| Etapa | O que fazer | Entregável |
|-------|-------------|-----------|
| **Segmentar Mercado** | Levantar segmentos, nichar alvo | Segmento-alvo definido |
| **Descobrir Cliente** | Caracterizar persona, identificar job, mapear jornada, identificar dor | Persona + Job + Dor priorizados |
| **Validar Solução** | Criar algoritmo core, MVP concierge, validar MVP | MVP validado com clientes reais |
| **Modelo de Receita** | Mapear uso, modelo de receita, quantificar valor, precificar, testar elasticidade | Pricing validado, LTV estimado |

### Fase 2: Pré-Seed (~18 meses)
```
Testar Estratégia de Aquisição → Refinar Métricas Chave → PMF
```

| Etapa | O que fazer | Entregável |
|-------|-------------|-----------|
| **Aquisição** | Mapear processo de compra, canais, ativação, vendas | CAC mensurado |
| **Métricas** | Refinar LTV/CAC, adequar modelo + aquisição | Unit economics saudáveis |
| **PMF** | Product-Market Fit comprovado | GMV, MRR estáveis |

### Fase 3: Seed (~18 meses) — Captar para Growth
```
Produto replicável → GTM → Preparar governança → Estruturar máquina
```

| Etapa | O que fazer |
|-------|-------------|
| **Produto** | Testar qualidade, melhorar algoritmo, UI/UX |
| **GTM** | Design thinking, refinar funil, CS, equipe |
| **Governança** | Modelagem financeira, cultura, legal |

### Fase 4: Série A+ — Growth & Expansão
```
Série A: Growth no segmento-alvo → Série B: Expansão para outros segmentos/produtos
```

### Métricas-Chave por Fase

| Fase | Métrica Principal | Meta |
|------|-------------------|------|
| Bootstrapping | Problem-Solution Fit | Clientes confirmam a dor |
| Pré-Seed | LTV/CAC ratio | > 3:1 |
| Seed | MRR growth | > 15% MoM |
| Série A | Net Revenue Retention | > 110% |

### Regras de Ouro
- **Não planeje o resultado, planeje o processo** de validação
- **Cada fase valida a anterior** — não pule etapas
- **Foco é uma das coisas mais importantes** — resolver um problema primeiro
- **Apaixone-se pelo problema** — o produto vai mudar, o problema persiste
- **Effectuation > Causation** no early-stage — use o que tem, não planeje o que não tem

### Fórmula Completa
```
Repertório + Pensamento Paralelo = Criatividade
Criatividade + Experimentação + Cocriação = Inovação
Inovação + Teste sobre Clientes e Soluções = Validação
Validação + Teste Modelo de Negócio = Startup
```

## Aplicação ao Quayer

### Status Atual (estimado)
- **Fase:** Bootstrapping → Pré-Seed (entre Validar Solução e Testar Aquisição)
- **Segmento:** PMEs que usam WhatsApp para atendimento
- **Persona:** Dono de PME com 2-10 atendentes no WhatsApp
- **MVP:** Plataforma multi-tenant de WhatsApp (em desenvolvimento)

### Próximas Etapas
1. Validar solução com clientes reais (MVP concierge ou early access)
2. Testar modelo de receita (pricing, willingness to pay)
3. Mensurar CAC e LTV iniciais
4. Buscar PMF com métricas comprovadas
5. Captar pré-seed quando LTV/CAC > 3:1

### KPIs para Acompanhar
- MRR (Monthly Recurring Revenue)
- Churn rate (mensal)
- CAC (Custo de Aquisição de Cliente)
- LTV (Lifetime Value)
- LTV/CAC ratio
- Ativação (% de trial → paying)
