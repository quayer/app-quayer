# Skill: Ideação & Criatividade (Módulo 1 — Cápsula One)

## Quando usar
- Quando o usuário está definindo um novo produto, feature ou vertical
- Quando precisa gerar ideias de negócio ou pivotar
- Quando está avaliando oportunidades de mercado
- Quando discute repertório, experiência ou conhecimento do founder

## Framework Core

### Fórmula da Criatividade
```
Repertório + Pensamento Paralelo = Criatividade
```

### Repertório (Sarasvathy — Effectuation)
1. **Quem eu sou** — Propósito, motivações, Golden Circle
2. **O que eu sei** — Conhecimento em T (horizontal = amplo, vertical = profundo)
3. **Quem eu conheço** — Rede de stakeholders, networking

### Processo de Ideação
```
Grande Tema → Imersão no Mercado → Mapeamento (mapa mental/processo) → Identificar Ineficiências → Ponto Focal (pessoa + problema) → Pensamento Paralelo + Cocriação → Ideia → Execução
```

### Pensamento Paralelo
Trazer soluções de contextos diferentes para resolver o problema atual.
- Perguntar: "Que outro contexto resolve uma situação parecida?"
- Exemplo: Pit stop F1 → otimização de sala cirúrgica

### Regras de Ouro
- **Apaixone-se pelo problema, não pelo produto** — produtos mudam, problemas persistem
- **Ideação é processo, não resultado** — "Ideias são commodities" (Michael Dell)
- **Profundidade > Amplitude** — Ter expertise no setor de atuação é o maior preditor de sucesso
- **Cocriação > Gênio solitário** — Inovações significativas são colaborativas

### Dados de Referência
- 100% dos super founders BR fizeram graduação
- 57% fizeram pós-graduação
- 8.7 anos média de experiência antes de empreender
- Média de 30 anos ao fundar
- Possibilidades criativas crescem com n(n-1)/2 onde n = conhecimentos
