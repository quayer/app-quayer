# Skill: Formação de Time Empreendedor (Módulo 1 — Cápsula One)

## Quando usar
- Quando o usuário discute co-founders, sócios ou parcerias
- Quando há conflitos ou divergências no time
- Quando está avaliando equity splits ou responsabilidades
- Quando precisa estruturar feedback ou alinhamento

## Framework Core

### Modelo de Time Ideal
**Perfil Individual:**
- Heterogeneidade (competências complementares: tech + business + domínio)
- Maturidade para dar e receber feedback

**Relação entre Sócios:**
- Alinhamento de objetivos (propósito + visão de futuro + tipo de jogo)
- Confiança mútua (índole + pessoal + competência)

### Dois Tipos de Conflito

| Operacional (saudável) | Afetivo (letal) |
|------------------------|-----------------|
| Divergência sobre tarefas | Brigas pessoais |
| "Devemos priorizar X ou Y?" | "Você é incompetente" |
| Amplia campo de visão | Mata startups boas |
| Natural em times diversos | Surge da escalada do operacional |

### Escalada: Operacional → Afetivo
```
Decisões diferentes → Conflito operacional → [sem feedback/confiança] → Conflito afetivo → Morte da startup
```

### Mecanismos de Mitigação
1. **Feedback:** Interpretar como informação sobre o TRABALHO, não sobre a PESSOA
   - Bom: "Essa feature ficou com latência alta, podemos otimizar?"
   - Ruim: "Você não sabe programar direito"
2. **Confiança (3 dimensões):**
   - Índole: quer o melhor para o negócio
   - Pessoal: quer o melhor para mim
   - Competência: sabe executar o que precisa

### Regras de Ouro
- **65% das startups falham** por conflito entre co-founders
- **Sweet spot: 2-3 co-founders** complementares
- **"Namore antes de casar"** — executem junto antes de formalizar
- **Sociedade = casamento** (confiança, objetivos comuns, crescimento mútuo)
- **Segurança psicológica** é o fator #1 de equipes de alto desempenho (Google Project Aristotle)

### Checklist para Avaliar Parceiro/Sócio
- [ ] Competências complementam as minhas?
- [ ] Tem experiência relevante no setor?
- [ ] Alinhamento: mesmo tipo de jogo (escala vs lifestyle)?
- [ ] Confio na índole?
- [ ] Confio na competência técnica?
- [ ] Já executamos algo junto com sucesso?
- [ ] Feedback funciona nas duas direções?
