# Skill: Segmentacao & Estrategia de Entrada no Mercado (Modulo 2 — Capsula One)

## Quando usar
- Quando o usuario esta definindo qual segmento de mercado atacar
- Quando precisa calcular TAM/SAM/SOM ou dimensionar mercado
- Quando esta avaliando se deve pivotar para outro nicho
- Quando discute estrategia de Go-To-Market (GTM)
- Quando cai na armadilha de querer atender todo mundo

## Framework Core

### Conceito: Mercado Cabeca de Praia (Beachhead Market)
Origem: Dia D na Normandia — os aliados escolheram um ponto focal de entrada com menos defesas para desembarcar toda a potencia e, a partir dali, expandir ponto a ponto.

```
Analogia: Pinos de Boliche
Derrubar o primeiro pino estrategico → usar a forca para derrubar os adjacentes → dominar todos
```

### Processo Empreendedor de Entrada
```
Nicho Cabeca de Praia → Dominar (70-80% share) → Expandir para Adjacentes → Construir Negocio Maior
```

**Expansao possivel por duas vias:**
1. Mesmo produto → novos segmentos com perfil parecido
2. Novos produtos → mesmo publico-alvo

### Duas Armadilhas Fatais

| Armadilha | Descricao | Consequencia |
|-----------|-----------|--------------|
| **Sindrome da China** | Estimar mercado gigante, chutar market share arbitrario (0,1%), brincar com planilha | Nao explica POR QUE o cliente compraria; hipoteses sem base |
| **Vender pra qualquer um** | Aceitar todo cliente que aparece, adequar produto para cada um | Sem estrategia de entrada, nenhum nicho validado, impossivel escalar |

### Por que Foco = PMF
```
1 segmento → 1 solucao profunda → 1 modelo de receita → 1 canal de aquisicao → 1 LTV/CAC a comprovar
```

Multiplos segmentos = multiplos LTVs e CACs = complexidade exponencial = impossivel provar PMF.

**Regra:** Startup e organizacao temporaria em busca de um modelo escalavel e replicavel (Steve Blank). O jogo dos primeiros dias NAO e crescimento — e VALIDACAO.

### Exemplos de Cabeca de Praia

| Empresa | Cabeca de Praia | Expansao |
|---------|-----------------|----------|
| Facebook | Alunos de Harvard (70-80% adocao) | Ivy League → universidades EUA → todo mundo |
| Nubank | Cartao de credito para jovens classe A/B sem historico | NuConta → investimentos → banco completo |
| Amazon | Livros online | Todas as categorias de e-commerce |

### 7 Perguntas para Escolher o Segmento (Bill Aulet / MIT)

Para cada nicho potencial, responder:

1. **Capitalizado?** O cliente tem dinheiro para pagar?
2. **Acessivel?** Consigo chegar a ele com minha equipe de vendas?
3. **Motivo para comprar?** Tem razao consistente ou ja esta satisfeito?
4. **Produto entregavel?** Consigo entregar algo funcional sem desenvolver muito?
5. **Concorrencia?** Ha concorrente muito estabelecido como obstaculo?
6. **Alavancagem?** Dominar este nicho me posiciona para expandir para outros?
7. **Alinhamento?** E condizente com paixoes e valores da equipe?

**Estrela de ouro:** O cliente esta com o "cabelo pegando fogo"? (dor extrema, sem solucao adequada)

### Processo Pratico de Segmentacao

```
1. Listar todos os segmentos possiveis (abrir leque)
2. Caracterizar tomador de decisao de cada um
   - B2C: genero, formacao, renda, localizacao, anseios
   - B2B: tipo empresa, setor, faturamento, tomador de decisao, desafios
3. Responder 7 perguntas (mesmo no chutometro)
4. Restringir para 3 segmentos prioritarios
5. Aprofundar informacoes desses 3 (detetive de dados + jornalista)
6. Responder 7 perguntas novamente com dados
7. Definir segmento cabeca de praia
```

### 4 Tecnicas de Levantamento de Informacoes

| Tecnica | Descricao |
|---------|-----------|
| **Detetive de dados** | Dados secundarios (internet, relatorios, IBGE) |
| **Jornalista** | Entrevistas com pessoas do perfil |
| **Antropologo** | Observacao do comportamento no momento de uso |
| **Personificacao** | Vivenciar a situacao do cliente em primeira pessoa |

### Regras de Ouro
- **Nao seja analista de mercado** — paralisia de analise mata mais que decisao imperfeita
- **Foco desde o dia zero** — cada segmento a mais multiplica a complexidade
- **Escalavel = LTV >> CAC** — descasamento entre lucro e custo de aquisicao
- **Replicavel = custo marginal baixo** — software e naturalmente replicavel
- **Validacao antes de crescimento** — provar modelo antes de escalar
