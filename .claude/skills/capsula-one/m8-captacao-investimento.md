## Framework Core

### Pensamento do Investidor — Entender o Jogo

**Ciclo de vida de um fundo VC (~10 anos):**
```
1. Preparar captacao (1-2 anos) → Atrair Limited Partners (LPs)
2. Montar fundo → LPs colocam capital, gestor entra com 1-2%
3. Deal flow (3-4 anos) → Pipeline de startups, selecao, aportes
4. Monitorar + Follow-on → Acompanhar, novos aportes para manter participacao
5. Exit → Venda (M&A), IPO ou venda para private equity
6. Devolver capital + lucro aos LPs
```

**O que o VC quer:**
- Startup com menor probabilidade de morrer
- Maior probabilidade de crescimento exponencial
- Retorno que compense as perdas do portfolio (maioria perde)
- Evento de liquidez em 5-7 anos

**Estatisticas brutais:**
- 2/3 das startups morrem antes do Seed
- Das que captam Seed, 30% chegam a Serie A
- Das Serie A, 17% chegam a Serie B
- 0,3% chegam a Serie F+

**Exemplo Uber:**
- Anjo entrou com US$1,25M por 24% (valuation US$5,2M)
- Diluicao ao longo das rodadas: 24% → 12%
- IPO: valuation US$82B → retorno de 7.312x
- MAS: esse e o caso raro. A maioria dos investimentos retorna 0.

### Rodadas de Investimento — Quando Captar

| Rodada | Momento | Objetivo | Origem |
|--------|---------|----------|--------|
| **FFF** | Ideacao/MVP | Testar ideia inicial | Family, Friends, Fools |
| **Anjo/Aceleradora** | PSF comprovado | 1 ano de runway para testar modelo | Investidores anjos |
| **Pre-Seed** | Testando GTM | Provar LTV/CAC, buscar PMF | Anjos, micro-VCs |
| **Seed** | PMF comprovado | Estruturar maquina, governanca, contratar | VCs early-stage |
| **Serie A** | Maquina validada | Growth agressivo, escalar | VCs institucionais |
| **Serie B+** | Crescimento acelerado | Expandir mercados, consolidar | VCs growth |

**Regra:** Antes do PSF, e quase impossivel captar de terceiros. Cada rodada financia o proximo objetivo de validacao.

### Valuation — Como Calcular o Montante

**Metodo Cash Burn (mais pratico para early-stage):**

```
1. Montar fluxo de caixa REALIZADO (ate hoje)
2. Projetar fluxo de caixa DURANTE a rodada (~6 meses captando)
3. Projetar fluxo de caixa POS-RODADA (12-18 meses)
   - Nova equipe (rampagem em 2 fases)
   - Novos custos (ads, ferramentas, contratacoes)
   - Projecao de receita com novos clientes
4. Somar cash burns mensais do pos-rodada = Necessidade de caixa
5. Adicionar margem de seguranca (~20%)
6. Necessidade total = Montante a captar
```

**Valuation:**
```
Valuation = Montante a captar / % de participacao cedida
Ex: R$600.000 / 10% = R$6.000.000 de valuation
```

**Exemplo da planilha:**
```
Soma cash burns pos-rodada (18 meses): R$510.000
Margem de seguranca: +R$90.000
Montante a captar: R$600.000
Diluicao: 10%
Valuation: R$6.000.000

Projecao: LTV/CAC sai de 1.8 → 2.7 (proximo do PMF)
Clientes novos/mes: de 3 → 6-7 (com nova equipe)
```

**Justificativa para investidor:**
- Mostrar Unit Economics realizado
- Mostrar projecao fundamentada (benchmark + testes ja feitos)
- Demonstrar que o capital leva ao proximo milestone (PMF, Serie A)

### Documentos Legais da Rodada

| Documento | Funcao |
|-----------|--------|
| **NDA** | Acordo de confidencialidade antes de abrir numeros |
| **Term Sheet** | Termos preliminares da rodada (nao-vinculante) |
| **Due Diligence** | Investidor audita a empresa (financeiro, legal, tech) |
| **Mutuo Conversivel** | Emprestimo que se converte em equity num evento futuro (mais simples que venda de equity direta) |
| **Acordo de Investimento** | Contrato final de aporte + participacao |
| **Acordo de Socios** | Regras entre socios (vesting, tag along, drag along) |

### Pitch Deck — Estrutura e Preparacao

**3 Tipos de Pitch:**

| Tipo | Formato | Slides | Uso |
|------|---------|--------|-----|
| **Apresentacao oral** | Falado, slides visuais | 10-12 | Demo day, eventos, aceleradoras |
| **Deck introdutorio** | Autoexplicativo, enviado | 5-6 | Primeiro contato com investidor |
| **Deck completo** | Autoexplicativo, detalhado | 12-15 | Analise aprofundada pelo investidor |

**Preparacao (antes de abrir PowerPoint):**
1. **Publico-alvo** — Quem vai ler/assistir? Perfil do investidor?
2. **Tipo de apresentacao** — Oral, introdutorio ou completo?
3. **Objetivo** — O que quero conseguir? (reuniao, aporte, parceria)
4. **Mensagem core** — Qual a informacao principal que ressoa com esse publico?
5. **Marcos da historia** — Que pontos reforcar para sustentar a mensagem?

**Regra:** Adaptar o pitch ao interlocutor. Investidor pragmatico = LTV/CAC. Investidor de impacto = impacto social. Nao usar o mesmo deck para todos.

**Estrutura classica do Pitch Deck de investimento:**

```
1. Capa (nome, tagline, logo)
2. Problema (dor real, dados de mercado)
3. Solucao (como resolve, diferencial)
4. Mercado (TAM/SAM/SOM, cabeca de praia)
5. Modelo de negocio (como ganha dinheiro)
6. Tracao (metricas, clientes, crescimento)
7. Unit Economics (LTV, CAC, LTV/CAC)
8. Concorrencia (posicionamento, diferenciais)
9. Time (founders, experiencia, complementaridade)
10. Roadmap (proximos passos, milestones)
11. A Rodada (montante, uso dos recursos, timeline)
12. Contato
```

### Quick Pitch — Regras de Apresentacao Oral

- Menos texto nos slides, mais na fala
- Usar voce como guia principal (presenca)
- Mensagem core repetida em diferentes momentos
- Linguagem adaptada ao publico (formal vs. coloquial)
- Contar historia, nao listar features
- Toda apresentacao tem UMA mensagem principal (modelo TED)

## Aplicacao ao Quayer
- **Momento atual:** PSF em validacao → rodada de anjos ou aceleradora e o proximo passo viavel
- **Montante a captar:** Calcular cash burn projetado para 18 meses (infra, marketing, primeiro hire) + 20% margem
- **Valuation method:** Cash burn projetado. Se precisa R$200K para 18 meses, cedendo 10% = valuation R$2M
- **Pitch core message:** "Barbearias perdem R$X/mes por atendimento caotico no WhatsApp. Quayer organiza isso em minutos — e o dono da barbearia ja usa WhatsApp o dia inteiro."
- **Tracao para o deck:** Numero de barbearias testando, NPS, tempo medio de resposta antes/depois, churn rate
- **Diferenciais para investidor:** Unit economics reais de barbearia (Gabriel tem experiencia), nicho cabeca de praia com expansao clara (saloes → clinicas → PMEs), modelo SaaS recorrente com churn naturalmente baixo
- **Estrategia de captacao:** Aceleradoras de SaaS/WhatsApp → anjos do ecossistema → pre-seed se PMF comprovado
- **Alternativa bootstrap:** Parceria com influencers (equity por audiencia) substitui capital de marketing. Validar LTV/CAC organicamente antes de captar
